Plan for the batch script
A SLURM array job. One script runs as 33 separate tasks, one per SRR ID, reading the IDs from metadata/SRR_Acc_List.txt in your repo.
Each task repeats tonight’s steps: prefetch, then fasterq-dump, then pigz.
Each task logs a read count check. It records the spot count, so you can compare all 33 against the SRA table in the morning.
Each task deletes its .sra file after compression succeeds. It only deletes after success, and the file can always be downloaded again. That saves ~58 GB.
Finished samples are skipped. If a sample’s .fastq.gz files already exist, that task does nothing. So SRR32154025 won’t be redone, and a failed job can be resubmitted safely.
At most 6 tasks run at once. That’s polite to the shared network and scratch, and it should still finish overnight. Each task requests 8 CPUs, 16 GB of memory, and up to 3 hours.
Logs go to logs/ildiko/ in your course folder, one file per task, so they persist after scratch purges.
The script is saved as scripts/ildiko/01_download_fastq.sbatch. The 01_ prefix keeps your pipeline steps in order.

nano scripts/ildiko/01_download_fastq.sbatch

#!/bin/bash
#SBATCH --job-name=fp_download
#SBATCH --partition=courses
#SBATCH --array=1-33%6
#SBATCH --nodes=1
#SBATCH --ntasks=1
#SBATCH --cpus-per-task=8
#SBATCH --mem=16G
#SBATCH --time=06:00:00
#SBATCH --output=/courses/BINF6430.202710/students/polyak.i/FinalProject/logs/ildiko/download_%A_%a.out

# Download one SRA run per array task, convert to FASTQ, compress, verify.
set -eo pipefail

# ---- Paths ----
PROJ=/courses/BINF6430.202710/students/polyak.i/FinalProject
RAW=/scratch/polyak.i/binf6430/FinalProject/raw
ACC_LIST=$PROJ/metadata/SRR_Acc_List.txt

# ---- Pick this task's SRR ID (line N of the list; strip any Windows line endings) ----
SRR=$(sed -n "${SLURM_ARRAY_TASK_ID}p" "$ACC_LIST" | tr -d '\r')
TMP=$RAW/tmp/$SRR

echo "Task ${SLURM_ARRAY_TASK_ID}: ${SRR} on $(hostname) at $(date)"

# ---- Skip if this sample already finished ----
if [[ -f "$RAW/${SRR}.done" ]]; then
    echo "${SRR} already done, skipping."
    exit 0
fi

# ---- Activate environment (aliases and shell functions don't exist in batch jobs) ----
eval "$(/home/polyak.i/.local/bin/micromamba shell hook --shell bash)"
micromamba activate fp-download

# ---- 1. Download .sra ----
prefetch "$SRR" -O "$RAW" --max-size 50G

# ---- 2. Convert to paired FASTQ (spot/read counts print to this log) ----
mkdir -p "$TMP"
fasterq-dump "$RAW/$SRR" -O "$RAW" -t "$TMP" -e "$SLURM_CPUS_PER_TASK"

# ---- 3. Compress (replaces .fastq with .fastq.gz) ----
pigz -p "$SLURM_CPUS_PER_TASK" "$RAW/${SRR}_1.fastq" "$RAW/${SRR}_2.fastq"

# ---- 4. Verify compressed files are intact ----
pigz -t "$RAW/${SRR}_1.fastq.gz" "$RAW/${SRR}_2.fastq.gz"

# ---- 5. Clean up only after everything above succeeded ----
rm -rf "$RAW/$SRR" "$TMP"
touch "$RAW/${SRR}.done"

echo "${SRR} finished at $(date)"
EOF

#!/bin/bash
#SBATCH --job-name=fp_kal_quant

#SBATCH --time=04:00:00
#SBATCH --output=/courses/BINF6430.202710/students/polyak.i/FinalProject/logs/ildiko/quant_%A_%a.out

# kallisto 0.48.0 quant, unstranded baseline, one sample per array task.
set -eo pipefail

# ---- Paths ----
PROJ=/courses/BINF6430.202710/students/polyak.i/FinalProject
RAW=/scratch/polyak.i/binf6430/FinalProject/raw
IDX=/scratch/polyak.i/binf6430/FinalProject/reference/gencode.vM30.kallisto_0.48.0.idx
OUTDIR=/scratch/polyak.i/binf6430/FinalProject/kallisto/baseline_unstranded
ACC_LIST=$PROJ/metadata/SRR_Acc_List.txt

# ---- Pick this task's SRR ID ----
SRR=$(sed -n "${SLURM_ARRAY_TASK_ID}p" "$ACC_LIST" | tr -d '\r')
echo "Task ${SLURM_ARRAY_TASK_ID}: ${SRR} on $(hostname) at $(date)"

# ---- Skip if already done ----
if [[ -f "$OUTDIR/${SRR}.done" ]]; then
    echo "${SRR} already quantified, skipping."
    exit 0
fi

# ---- Activate environment ----
eval "$(/home/polyak.i/.local/bin/micromamba shell hook --shell bash)"
micromamba activate fp-quant
kallisto version

# ---- kallisto only creates the last folder level, so make the parent first ----
mkdir -p "$OUTDIR"

# ---- Quantify (no strand flag = unstranded; no -b = no bootstraps) ----
kallisto quant -i "$IDX" -o "$OUTDIR/$SRR" -t "$SLURM_CPUS_PER_TASK" \
    "$RAW/${SRR}_1.fastq.gz" "$RAW/${SRR}_2.fastq.gz"

touch "$OUTDIR/${SRR}.done"
echo "${SRR} finished at $(date)"

rsync is the standard tool for this kind of copy. It copies folders, keeps file dates, and if you run it again later, it only copies what has changed.
-a (“archive”) copies folders and everything inside them, and keeps file dates and permissions.
-v lists each file as it’s copied.
--exclude='*.done' skips the marker files, which only matter in scratch.
The trailing / on the source path means “copy what’s inside this folder.” Without it, rsync would create an extra baseline_unstranded/ folder inside the destination.
